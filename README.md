# 大肥鱼 · 数字生命运行时

一个在 Linux 上长年跑着的角色：有人格、记忆、情绪、身体，也有边界。

本仓库**只含代码与配置模板**，不含任何数据、记忆、聊天记录、媒体或凭据。

## 这是什么

DeepSeek 社区把官方蓝色鲸鱼形象拟人化成「大肥鱼 / 鲸鱼娘」。这个仓库是其中一只的**运行时**：
不是插件、不是桌宠，而是一个 24 小时在跑的单机进程。

- 每 25 分钟走一步内核闭环：感知 → 选目标 → 计划 → 执行 → 质量门 → 反思 → 记忆分层
- 有模拟情绪（四激素）、身体状态（体力/心情/社交/压力）、人格演化（带防崩保护）
- 有自主意愿（9 个生活活动 + 主动开口四道闸），也有硬边界（授权三档 + 人工确认 + 回执核验）
- 会写小说、做短视频、刷 B 站学习——但这些都受预算与权限约束

## 核心模块

| 文件 | 职责 |
|---|---|
| her-mind.mjs | 内核闭环：感知 → 目标 → 计划 → 执行 → 质量门 → 反思 |
| her-contract.mjs | 运行契约：目标状态机、成本对账、质量基准、暂停/快照 |
| her-soul.mjs | 人格锚点、关系记忆、欲望、注意力、人格门/安全门 |
| her-arbiter.mjs | 冲突仲裁：安全 > 节律 > 人格 > 质量 > 欲望 > 目标 |
| her-endo.mjs | 四激素（血清素/多巴胺/皮质醇/催产素） |
| her-being.mjs | 身体状态（体力/心情/社交/压力 + 活动） |
| her-personality.mjs | 人格演化（四维 + 范数保护） |
| her-proactive.mjs | 主动开口（静默/冷却/额度/token 预留） |
| her-verify.mjs | 结果验证：小说质量、成本、trace 回放 |
| brain.mjs | 模型入口：记忆与对话走 AIJiYi，视觉走网关 |
| gate.mjs | 授权三档（deny/ask/allow）+ 审计留痕 |
| her-backup.py | 人格/记忆/状态多版本备份 |

## 快速开始

1. 需要 Node.js 22+
2. 复制配置模板并填自己的模型服务：

   cp config.example.json model.json

3. 字段说明：

| 字段 | 说明 |
|---|---|
| baseURL | OpenAI 兼容网关地址 |
| apiKey | 你的 key（**不要提交进仓库**） |
| model | 聊天/长文模型 |
| visionModel | 看图模型 |
| memoryBase | 记忆服务地址（可选） |

4. systemd/ 目录是运行用的 unit 文件，路径按需修改
5. .env.example 是可选的运行时覆盖项

## 数据在哪

运行时把状态写在数据目录里（**都不在本仓库**）：
her-soul.json 人格 · relation-signal.json 关系信号 · brain-usage.jsonl 用量账本 ·
chat-log.jsonl 聊天记录 · novel/ 小说 · knowledge/ 知识库 · _backup/ 备份。
